# Images

Drop your photos in this folder, then uncomment the matching `<img>` tag in the HTML.
Each placeholder in the markup already names the file it expects.

| File | Used on | Suggested size |
| --- | --- | --- |
| `hero.jpg` | Homepage hero | 1200 × 1500 (portrait 4:5) |
| `piece-01.jpg` … `piece-06.jpg` | Homepage "Selected work" grid | 1000 × 1000 (square) |
| `gallery-01.jpg` … `gallery-12.jpg` | Gallery page | 1000 × 1000 (square) |
| `materials.jpg` | Materials section | 1250 × 1000 (5:4) |
| `maker.jpg` | About section | 1250 × 1000 (5:4) |
| `og-image.jpg` | Link previews on social / iMessage | 1200 × 630 |

Two things worth doing before you upload:

1. **Compress them.** Run them through Squoosh (squoosh.app) or export at ~80% JPEG
   quality. Phone photos are often 4–8 MB each and will make the site feel slow.
2. **Write real alt text.** Replace `alt=""` with a short description of what's in the
   photo — it's what screen readers announce and what search engines read.
